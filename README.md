# CortexWave - Company Website

Corporate website for **CortexWave Pty Ltd** — an Australian software company.

**Live:** [https://cortexwave.com.au](https://cortexwave.com.au)

## Tech Stack

- **Next.js 16** (App Router, TypeScript)
- **TailwindCSS 4**
- **Framer Motion** (animations)
- **Lucide React** (icons)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
npm start
```

## Deployment

Deployed on **DigitalOcean App Platform** with auto-deploy from the `main` branch.
